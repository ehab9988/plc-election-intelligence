# API

OpenAPI docs are auto-generated by FastAPI at `/docs` (Swagger UI) and
`/openapi.json` once the API is running — this file is a narrative index,
not a duplicate of the schema.

Base path: `settings.api_v1_prefix` = `/api/v1` (`services/api/app/config.py`).

Candidate seat probability is deliberately **not** inlined into
`/candidates/{id}` — it always comes from a specific, timestamped
`ForecastRun` via `/forecast/{run_id}/candidates`, so a probability shown
in the UI is always traceable to the model version and data cutoff that
produced it (section 65 "source button" principle applied to model
outputs, not just facts).

## Not implemented in this build

- `/electoral-lists` as a standalone resource (currently only reachable
  through forecast results and the seed data; the Flutter client's
  `PartyRepository.listElectoralLists()` falls back to bundled fixture
  data pending this).
- Admin-only data-review endpoints (poll approval queue, duplicate-entity
  merge, source-conflict resolution — section 27). The underlying tables
  (`entity_conflicts`, `audit_logs`) exist; the endpoints do not yet.
- Export endpoints (CSV/PDF, section 38).
- API-key-authenticated commercial access (section 37) — `ApiKey` model
  exists, no middleware enforces it yet.
